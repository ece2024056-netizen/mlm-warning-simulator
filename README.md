# MLM Pyramid Saturation Simulator

An interactive single-page simulator that shows how multi-level marketing recruitment models grow geometrically, exceed population limits, and concentrate risk/losses in lower levels.

## Features

- Recruitment growth curve
- Visual pyramid levels
- World-population limit estimate with live ticking display
- USD / INR currency conversion
- Expected loss and expected net calculations
- FTC-style MLM risk and scam warning section
- Local privacy policy: no user data is collected, stored, sent, or shared

## Run Locally

Open `index.html` in a browser.

## Deploy With GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `README.md`.
3. Go to repository **Settings > Pages**.
4. Set source to the default branch and root folder.
5. Save, then open the generated GitHub Pages URL.

## Notes

The population counter is a local live estimate seeded from current global estimates and linked to Worldometer for reference. The page is educational and is not legal or financial advice.
